# 南昌旅游自定义路线地图工具 视觉风格规范

> 文档状态：风格已审查通过（与「风格预览.html」实际落地参数一致）
> 设计语言：浅色液态玻璃 + iOS 式秩序感
> 关键词：克制、通透、轻盈、流畅

---

## 一、设计基调

### 1. 核心理念
以**液态玻璃材质 + iOS 式秩序感**为整体语言，让地图和点位成为视觉主角，所有控件退到背景层，需要操作时才高亮。

### 2. 落地原则
1. **玻璃是材质，不是装饰**：玻璃面板只用于悬浮在地图之上的组件（底部导航、侧边栏、搜索框、弹窗、FAB 按钮），页面内部信息容器用纯色或极浅灰，避免层层模糊导致发虚。
2. **内容优先**：控件通过高透明度和模糊弱化存在感，不与点位争夺注意力。
3. **克制用色**：品牌强调色仅用于主按钮、选中态和链接，不大面积铺色。
4. **Web 实现边界**：浏览器可稳定实现毛玻璃（backdrop-filter blur + saturate）、半透明描边、柔和高光和弹性动效；不依赖实时边缘折射、镜面扭曲等 Web 无法还原的效果。

---

## 二、设计 Token（Design Token）

所有颜色、圆角、阴影、动效统一以 CSS 变量定义，浅色/深色切换只改变量，后续换主题成本极低。

| --text-3 | #aeaeb2 | 弱化文字、占位、禁用 |

### 4. 圆角

| Token | 值 | 应用 |
|-------|----|------|
| --r-xl | 24px | 底部导航、点位详情卡片 |
| --r-l | 20px | 侧边栏、路线卡片、筛选面板 |
| --r-m | 14px | 按钮、输入框、清单条目 |
| --r-s | 10px | 小标签、内嵌按钮 |
| 胶囊 | 999px | 搜索框、标签 chip、导航项 |

### 5. 阴影

- 小阴影 --shadow-s：`0 2px 8px rgba(0,0,0,.05), 0 1px 2px rgba(0,0,0,.04)`
- 中阴影 --shadow-m：`0 8px 24px rgba(0,0,0,.08), 0 2px 8px rgba(0,0,0,.04)`
- 大阴影 --shadow-l：`0 24px 60px rgba(0,0,0,.14), 0 8px 20px rgba(0,0,0,.08)`
- 深色模式阴影整体加深（透明度 .4 / .5 / .6）。
- 玻璃组件的层次感主要靠模糊 + 描边，阴影只做辅助，杜绝硬边重投影。

### 6. 玻璃模糊

- 统一模糊参数：`blur(24px) saturate(1.8)`。
- 玻璃面板背景透明度区间 0.55 ~ 0.78，配合 1px 半透明描边勾勒边缘。

## 三、地图底图样式

地图底图需自定义样式（高德/Mapbox 均支持），整体降饱和，隐藏底图自带的无关 POI 标注，让自定义 Marker 成为视觉焦点。

### 1. 浅色底图

| 元素 | 色值 |
|------|------|
| 底图背景 --map-bg | #e9ede6 |
| 水系 --map-water | #a9c9e2 |
| 水系高光 --map-water-2 | #c3dcef |
| 绿地 --map-green | #c9dfbf |
| 主干道 --map-road | #fbfcf9 |
| 支路 --map-road-2 | #d9ded5 |
| 建筑区块 --map-block | #e3e6df |
| 行政区边界 --map-boundary | rgba(90,110,90,.28)，虚线 6/8 |

### 2. 深色底图

| 元素 | 色值 |
|------|------|
| 底图背景 | #1c1f1d |
| 水系 | #27435c（高光 #31546f） |
| 绿地 | #263527 |
| 道路 | #2e322f（支路 #262a27） |
| 建筑区块 | #242824 |
| 行政区边界 | rgba(180,200,180,.18) |

### 3. 行政区高亮
选中行政区时，边界用强调色 15% 透明描边 + 同色 5% 填充；全选时不显示边界，避免界面杂乱。

## 四、字体与排版

### 1. 字体栈
```
-apple-system, BlinkMacSystemFont, "SF Pro SC", "PingFang SC", "Microsoft YaHei", sans-serif
```
全用系统字体，零加载成本；Mac 为原生 SF 质感，Windows 自动回退雅黑。

### 2. 数字处理
启用 `font-variant-numeric: tabular-nums`，时长、数量统计跳动时保持等宽不抖动。

### 3. 字号阶梯

| 层级 | 字号 | 字重 |
|------|------|------|
| 页面大标题（规划页） | 26px | 700 |
| 详情点位名称 | 18px | 600 |
| 卡片/清单标题 | 14-16px | 600 |
| 正文、简介 | 13.5-14px | 400 |
| 分类标签、次要信息 | 12px | 500 |
| 辅助小字 | 11px | 400 |

- 行高 1.4 ~ 1.65，中文不用斜体。
- 层级靠字重和颜色区分，不堆字体数量。

## 五、图标与 Marker 规范

### 1. 图标
- SF Symbols 风格线性图标，圆润描边 1.5 ~ 2px，统一 20/24px 尺寸网格。
- 选中态可由线性变填充，不更换图标体系。
- 全部使用内联 SVG，不使用 emoji。

### 2. Marker
- 样式：白色描边圆形徽章，内圈分类色，外圈 2.5px 白边 + 极淡投影，放弃传统水滴针造型。
- 尺寸：常规 Marker 26px（含外框 30px 热区）；配套点 18px（热区 22px），视觉自然弱化。
- 悬停：放大 1.18 倍，弹性曲线。
- 选中定位：外圈强调色光圈扩散动画（pinFlash，1.1 秒）。
- 已打卡：整体不透明度降至 35%。
- Marker 内部小图标统一 13px 线性白色（配套点 10px）。

## 六、动效体系

### 1. 统一参数

| 类型 | 时长 | 场景 |
|------|------|------|
| 微交互 | 150-200ms | 按钮按下、悬停 |
| 常规过渡 | 250-300ms | 面板、筛选、导航切换 |
| 进场动画 | 350-400ms | 弹窗、卡片进场 |

- 标准缓动：`cubic-bezier(.32,.72,0,1)`，起步快、收尾柔。
- 弹性缓动：`cubic-bezier(.34,1.3,.64,1)`，用于 Marker、药丸滑块等需要轻微回弹的元素。
- 动画只作用于 `transform` 和 `opacity`，不触发重排。

### 2. 场景动效

| 场景 | 效果 |
|------|------|
| 按钮按下 | 缩放至 .97 + 轻微变暗，松开回弹 |
| 筛选面板 | 从按钮锚点缩放淡入（scale .94 → 1） |
| 点位详情 | 淡入 + 轻微上浮；窄屏为底部上滑 |
| 路线卡片展开 | 高度平滑过渡，箭头旋转 180°，内容淡入下滑 |
| 底部导航 | 激活药丸在两个标签间弹性滑动，页面淡入淡出 |
| 路线连线 | stroke-dashoffset 画线动画，600ms 一次，不重复 |
| 新增点位 | Marker 轻微弹跳（.8 → 1.05 → 1），清单条目滑入 |
| Toast | 顶部下滑出现，2.6 秒自动上滑消失 |
| 复位 | 地图舞台轻微缩放回弹 |

### 3. 无障碍
响应系统 `prefers-reduced-motion`，用户开启减少动效时，所有动画与过渡时长压缩至 0.01ms。

## 九、可实现性与降级方案

1. **技术基础**：全部效果基于原生 CSS（backdrop-filter、CSS 变量、@supports）+ 少量 JS 状态控制，无需重型动画库。
2. **浏览器兼容**：现代 Edge / Chrome / Safari 完整支持，Firefox 新版默认开启。
3. **降级策略**：
   - `@supports not (backdrop-filter: blur(1px))` 时，玻璃面板降级为 --glass-bg-strong 纯色半透明，功能与可读性不受影响。
4. **性能约束**：
   - 同屏玻璃面板控制在 5 个以内，禁止玻璃嵌套玻璃。
   - 地图拖拽期间可临时降低模糊半径，松开恢复。
   - 模糊元素只对 transform/opacity 做动画，避免模糊半径实时变化触发重绘。
   - 长清单使用常规文档流，离屏条目不额外渲染模糊层。

## 十、风格禁止事项

1. 禁止玻璃面板层层嵌套（模糊套模糊）。
2. 禁止大面积使用强调色铺底，强调色只做点状激活。
3. 禁止硬边重阴影、纯黑纯白大面积对比。
4. 禁止使用 emoji 代替图标，图标统一内联 SVG 线性体系。
5. 禁止引入与系统色板无关的随机彩色，新增颜色必须从现有 Token 派生。
6. 禁止使用高饱和底图 POI 标注干扰自定义 Marker。
