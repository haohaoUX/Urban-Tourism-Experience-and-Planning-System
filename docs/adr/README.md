# 架构决策记录（ADR）

本目录保存项目关键设计决策的来龙去脉。每条 ADR 记录一次「在当时的信息下」做出的选择，包含背景、决策、理由、备选方案与后果，避免后来的人（包括未来的自己）反复推翻已经讨论过的问题。

说明：ADR-0001 ~ 0004 由刘克在 2026-11-12 按既有的技术选型、架构与设计文档追溯整理，**不是会议纪要**，具体的决策日期与参与人待组长与模块负责人确认后补填。确认前，这四条记录只作为「目前代码为什么长这样」的说明材料。

## 新增 ADR

复制下面的模板到 `docs/adr/NNNN-<kebab-case-标题>.md`，编号连续，不要复用已废弃编号。

```markdown
# NNNN. 决策标题

- 状态：提议中 / 已采纳 / 已废弃 / 被 NNNN 取代
- 日期：YYYY-MM-DD
- 决策人：

## 背景

当前面临什么问题，有哪些约束（时间、人力、技术债）。

## 决策

我们决定做什么，一句话说明。

## 理由

为什么这样选，逐条列出支撑事实。

## 备选方案

| 方案 | 优点 | 缺点 | 为何未采用 |
| --- | --- | --- | --- |

## 后果

采用后需要承担的成本、带来的收益、需要在什么条件下重新评估。
```
