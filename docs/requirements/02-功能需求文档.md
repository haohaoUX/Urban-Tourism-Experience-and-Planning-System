# 南昌旅游自定义路线地图工具 功能需求文档

> 文档状态：功能讨论整理版（待审查）
> 技术形态：Web 端前后端项目，浏览器访问
> 产品定位：聚焦南昌城市短途旅游的轻量化自定义行程规划地图工具

---

## 一、产品定位与设计原则

### 1. 产品定位
一款聚焦南昌城市短途旅游的**轻量化自定义行程规划地图工具**。核心逻辑是「用户自主选点 → 一键生成路线」，剔除与旅游无关的冗余点位，仅保留游玩、餐饮、逛购及出行刚需配套四类点位，支持多维度筛选和独立路线管理，满足游客按需规划专属游览行程的需求。

### 2. 设计原则
1. **新颖差异化**：不照搬市面上同类产品的老套设计，通过双模式生成、标记模式、自定义备注等细节形成差异。
2. **实用轻量化**：功能只围绕「选点 → 规划路线」核心流程，不堆砌无关模块。
3. **可落地实现**：全部功能可通过常规 Web 前后端技术 + 通用地图 API 实现，不依赖大型公司级技术实力。
4. **风格与功能分离**：本文档只讨论功能，不涉及 UI 视觉风格。

---

## 二、整体页面结构

### 1. 底部主导航栏
页面底部设置主导航栏，共两个标签页：

| 顺序 | 标签名称 | 页面职责 |
|------|----------|----------|
| 第一个 | 地图 | 主地图浏览区，浏览点位、筛选、搜索、挑选点位加入待选清单 |
| 第二个 | 规划 | 行程管理区，集中放置待选点位清单、一键生成路线按钮、已生成路线列表 |

### 2. 数据同步规则
- 地图页左侧侧边栏与规划页的待选清单**实时同步更新**。
- 用户在地图页添加/移除点位时，两侧清单同步变化，无需切换页面即可查看选点进度。

---

## 三、点位分类体系

共分为两大类 4 小类，不同类别用不同颜色 Marker 区分，功能边界清晰。

| 类别 | 颜色标识 | 包含内容 | 是否参与路线生成 |
|------|----------|----------|------------------|
| 景点 | 蓝色 | 公园、古迹、展馆、景区等游玩打卡点 | 是 |
| 正餐美食 | 橙色 | 本地特色菜馆、正餐门店 | 是 |
| 休闲市集小店 | 绿色 | 老街、文创店、市集、特色逛购点位 | 是 |
| 配套服务点位 | 浅灰色 | 公共卫生间、便利店、酒店、地铁出入口 | 否（仅作地图参考） |

## 四、地图页功能

### （一）主地图基础规则
- 地图范围：南昌市全域。
- 核心特性：主地图仅用于点位浏览，**永远不渲染任何已生成的游览路线**，保证地图界面清爽。
- 已生成路线的连线只在规划页的路线独立小地图中展示。

### （二）左侧侧边栏
采用**极简按钮式设计**，不做整体折叠，核心为「筛选」「标记」两个按钮，待选点位清单常驻在按钮下方。

#### 1. 筛选按钮
- 常态收起，仅显示按钮本体。
- 点击展开筛选面板，内含两组复选框：
  - **行政区筛选**：东湖区、西湖区、红谷滩区、青云谱区、青山湖区、新建区。
  - **点位类型筛选**：景点、正餐美食、休闲市集小店、配套服务点位，共 4 类独立开关。
- 两层条件**交集生效**，默认全部勾选，页面加载即可看到南昌全域所有旅游点位。
- 勾选/取消勾选条件，地图实时同步更新对应点位。
- 再次点击「筛选」按钮，面板收起，已选筛选条件持续生效。

#### 2. 标记按钮
- 默认未激活，地图正常显示所有符合筛选条件的点位。
- 点击激活「仅显示待选点位」模式，地图自动隐藏所有未加入待选清单的点位，只保留用户挑选过的点位。
- 再次点击则退出该模式，恢复完整点位显示。

#### 3. 待选点位清单（地图页常驻）
- 位于两个按钮下方，与规划页清单实时同步。
- 详细功能见「第六部分：待选点位清单模块」。

### （三）顶部点位搜索框
- 地图页顶部居中设置搜索框。
- 支持输入点位名称关键词搜索（如"滕王阁""万寿宫"）。
- 搜索后自动定位到对应点位、高亮 Marker 并弹出详情气泡。
- 解决手动拖动地图查找目标点位效率低的问题。

### （四）点位悬停预览
- 鼠标悬停在地图任意点位 Marker 上时，无需点击即可弹出极简提示标签。
- 标签仅展示「点位名称 + 分类标签」，字号小于正式详情弹窗。
- 鼠标移开后标签自动消失，不影响正常点击弹出详情气泡。
- 适配 Web 端鼠标交互，提升大范围扫点浏览效率。

### （五）筛选条件自动记忆
- 用户设置的行政区、点位类型筛选条件自动保留生效。
- 切换「地图/规划」标签页、刷新页面后，筛选条件保持上次勾选状态。
- 仅当用户手动修改、清空筛选时才变化。
- 数据存储在浏览器本地（localStorage），不依赖账号系统，零后端成本。

### （六）选中行政区边界高亮
- 勾选单个/多个行政区时，地图上对应行政区的边界线同步高亮显示。
- 边界采用半透明浅色描边，不遮挡点位 Marker。
- 取消勾选行政区后，对应边界高亮消失。
- 全选所有行政区时不显示边界，避免界面杂乱。
- 调用通用地图 API 的行政区边界数据即可实现。

### （七）地图视图一键复位
- 地图右下角增加「复位视角」按钮。
- 点击后地图自动缩放、平移到南昌市全域默认初始视角。
- 不改变任何筛选和选点状态，仅调整地图可视范围。

## 五、点位详情弹窗模块

### 1. 基础展示规则
点击任意点位 Marker 弹出详情气泡，内容按点位类型差异化展示。

**统一结构：**
- 大字：点位名称。
- 旁侧小字：分类 | 所属行政区。

**可规划点位（景点/正餐美食/休闲市集小店）：**
- 点位简介。
- 开放时间。
- 推荐停留时长。
- 底部设「添加到路线」按钮。

**配套服务点位：**
- 点位简介。
- **无推荐停留时长**。
- **不设「添加到路线」按钮**，仅作地图参考。

### 2. 添加状态联动
- 未添加的点位：气泡显示「添加到路线」按钮，可点击。
- 已添加的点位：按钮变为「已添加」并置灰不可点击。
- 从待选清单中移除该点位后，按钮恢复为可点击的「添加到路线」。
- **单个点位不可重复添加**到待选清单。

### 3. 周边点位快速查看
- 详情气泡内增加「查看周边」按钮。
- 点击后弹出周边点位列表，默认显示 500 米范围内的点位。
- 可切换筛选类型（全部/景点/美食/休闲）。
- 列表内点击点位可直接跳转定位并弹出详情。
- 再次点击「查看周边」或点击空白处收起列表。
- 基于点位坐标计算距离实现，无需额外接口。

### 4. 点位自定义备注
- 详情气泡内设「添加备注」输入框，最多支持 50 字。
- 添加备注后，待选清单对应点位条目旁显示备注小图标，悬停可查看完整内容。
- 最终生成的文字行程里附带备注内容。
- 满足用户记录个性化安排（如"看日落最佳时间""必吃某道菜"）的需求，纯文本存储。

### 5. 消费/门票参考信息
- 正餐美食类显示「人均参考：¥XX-XX」。
- 收费景点显示「门票参考：¥XX」。
- 免费点位/配套服务点不显示该字段。
- 信息为静态参考值，提前录入点位库，不做实时购票跳转，不对接实时票务系统。

## 六、待选点位清单模块

待选点位清单是用户从主地图手动挑选点位、准备生成路线的「点位临时收纳栏」，相当于购物车。地图页左侧与规划页各展示一份，实时同步。

### 1. 数量统计
- 顶部实时显示「已选择：X 个点位」。
- 数量随添加/移除实时更新。

### 2. 条目展示
- 每个点位条目显示：点位名称 + 分类小字标签 + 单个删除按钮。
- 分类标签方便快速区分点位类型。

### 3. 防重复规则
- 单个点位不可重复添加至清单。
- 已添加点位的气泡按钮置灰为「已添加」。

### 4. 数量提醒规则
- **不设添加上限**。
- 点位数量达到 15 个时弹出首次友好提醒（提示点位较多，可能影响单日游览体验）。
- 之后每新增 5 个（20、25、30……）再次弹出同类提醒。
- 提醒仅作友好提示，不限制用户继续添加。

### 5. 单个移除与一键清空
- 支持单个点位移除。
- 设「一键清空」按钮，可快速清空全部已选点位。

### 6. 点击定位联动
- 点击清单内任意点位条目，主地图自动居中定位到该点位，并高亮对应 Marker。

### 7. 点位拖拽手动排序
- 鼠标按住点位条目即可上下拖拽，松开后顺序固定。
- 排序结果实时保存。
- 生成路线时，可选择是否沿用该手动顺序。
- 前端成熟拖拽组件即可实现。

### 8. 清单微型类型筛选
- 清单顶部增加「全部/景点/美食/休闲」快捷选项。
- 点击后清单仅显示对应类型点位，不影响实际已选点位，仅临时过滤查看。
- 默认显示全部。

### 9. 自定义分组标签
- 支持给待选点位打自定义分组标签（如"第一天""上午场""备选"）。
- 可创建新标签，支持按标签批量筛选、批量移除。
- 标签仅作清单内分类标记，不影响路线生成逻辑。
- 轻量化满足多日/时段分类需求，不做复杂的多日行程拆分。

## 七、路线生成与规划页模块

### 1. 一键生成路线
- 用户选点完成后，在规划页点击「一键生成路线」按钮。
- 基于当前待选清单生成完整游览路线。
- 生成成功后**仅弹出成功提示**，页面不自动跳转，由用户手动查看路线。

### 2. 双模式路线生成
点击生成后提供两种模式可选，兼顾智能与自主：

| 模式 | 排序逻辑 | 适用场景 |
|------|----------|----------|
| 顺路最优模式 | 系统基于点位间距离自动计算最优游览顺序，尽量减少绕路 | 单日集中游玩、不想自己排序 |
| 清单顺序模式 | 严格按照待选清单里用户排好的顺序生成，不调整点位先后 | 用户已有明确先后安排 |

- 顺路最优模式采用轻量 TSP 近似算法，20 个点位以内可前端计算，性能足够。
- 生成后仍可在路线详情里微调顺序。

### 3. 路线列表与卡片
- 所有生成路线以卡片形式存放在路线列表。
- **默认折叠状态**，卡片仅展示「路线名称 + 包含点位数量」两项概要信息。
- 点击卡片展开详情。

### 4. 路线命名
- 支持用户自定义命名。
- 默认按生成顺序命名为「路线1、路线2、路线3……」。

### 5. 路线删除
- 支持单条路线删除。

### 6. 路线展开详情
点击卡片展开后展示两部分内容：

**（1）独立小地图**
- 仅渲染当前路线包含的点位与游览顺序连线。
- 无筛选功能。
- 完整呈现整条路线。

**（2）文字行程清单**
- 对应路线的点位序列说明。
- 附带用户自定义备注。

### 7. 生成后点位顺序微调
- 已生成路线支持在详情内直接调整点位顺序。
- 文字行程列表里的点位可拖拽排序。
- 每调整一个位置，小地图游览连线自动重绘。
- 同时自动重新计算总游览时长，无需重新点击生成按钮。

### 8. 路线总时长自动估算
- 展开路线详情后自动计算全程预估总时长。
- 时长组成：所有点位推荐停留时长之和 + 点位间通勤预估时长。
- 通勤模式可选：默认驾车，可切换步行，切换后通勤时长自动更新。
- 显示格式：「预估总时长：X 小时 X 分钟」。
- 通勤时长调用地图 API 路径规划接口获取。

### 9. 路线复制
- 路线卡片旁设「复制」按钮。
- 点击生成完全相同的路线副本，命名自动加「副本」后缀。
- 方便做多方案对比，不用重复选点。

### 10. 纯文本导出
- 路线详情内设「复制行程」按钮。
- 点击后将点位顺序、停留时长、用户备注按格式整理好，复制到剪贴板。
- 可直接粘贴到笔记软件，不做复杂的分享链接、海报功能。

## 八、轻量化辅助功能

### 1. 点位收藏夹
- 独立于待选清单的收藏功能，用于长期保存感兴趣的点位。
- 点位详情气泡内设「收藏」按钮，收藏后进入独立收藏夹。
- 收藏夹入口放在左侧侧边栏底部，点击展开查看。
- 支持批量从收藏夹添加到待选清单。
- 与待选清单完全独立，互不影响，区分「种草收藏」与「本次规划」两个场景。
- 本地存储实现。

### 2. 已打卡点位标记
- 点位详情内可标记/取消「已去过」。
- 标记后 Marker 变为半透明显示。
- 筛选面板里可选择「隐藏已打卡点位」。
- 规划路线时不自动排除，仅做视觉区分。
- 适合本地用户或多次游玩用户快速筛选没去过的点位，不做社交点评。

## 九、已确认的核心规则汇总

1. 底部主导航仅「地图」「规划」两个标签页。
2. 主地图仅用于点位浏览，永远不渲染已生成的游览路线。
3. 点位分为 4 类，配套服务点位不可加入路线。
4. 单个点位不可重复添加到待选清单。
5. 待选清单 15 个起每 5 个弹出友好提醒，不设数量上限。
6. 路线卡片折叠态仅显示「路线名称 + 点位数量」。
7. 路线生成成功后仅弹出提示，不自动跳转页面。
8. 左侧侧边栏采用「筛选」「标记」双按钮设计，待选清单常驻。
9. 地图页与规划页待选清单实时同步。
10. 所有用户数据优先采用浏览器本地存储，不强制登录。

## 十、本次暂不加入的功能

| 功能 | 暂不加入原因 |
|------|--------------|
| 用户注册登录系统 | 所有数据存本地即可满足单机使用，后续可扩展 |
| 社交分享、路线广场 | 聚焦个人规划，不做社区属性 |
| 实时人流、实时票价 | 需对接第三方大数据，成本高且非核心需求 |
| 酒店预订、门票购买 | 脱离核心规划流程，过于臃肿 |
| 多端同步、APP 适配 | 优先保证 Web 端核心体验 |
